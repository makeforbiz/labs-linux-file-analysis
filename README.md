## Как работать с файлами

Каждый файл является учебным заданием, созданным специально для отработки конкретных навыков.

Немного о некоторых файлах:

1. `systemd-update` – ELF, который копирует себя и проверяет наличие интернета. Учит полному циклу анализа.
2. `landscape.png` – картинка с вшитыми файлами. Учит поиску и извлечению скрытых файлов.
3. `mbr.bin` – реальный испорченный сектор. Учит восстановлению файлов вручную.
4. `payload` – сетевой дамп с вложенными файлами. Учит многоуровневому статическому и динамическому анализу.
5. `transaction_monitor` – подозрительный файл с банковского сервера. Учит применению всех базовых навыков динамического анализа из курса.

Важно: все файлы безопасны и предназначены для обучения.

## Чему вы научитесь

**Первичный осмотр файла:**
- Определять истинный тип через `file` и магические числа.
- Находить скрытые IP, домены и команды через `strings`.
- Читать hex-дамп через `xxd` и находить сигнатуры.
- Извлекать вшитые файлы с помощью `dd`.

**Анализ ELF:**
- Читать ELF-заголовок и находить точку входа.
- Вычислять размер вшитого файла через `readelf`.
- Находить `main` в stripped-бинарниках через `objdump`.

**Динамический анализ:**
- Отслеживать системные вызовы через `strace`.
- Перехватывать библиотечные функции через `ltrace`.
- Выявлять самокопирование, фоновый запуск, сетевую активность.

**Продвинутые техники:**
- Восстанавливать испорченные заголовки файлов.
- Объяснять механизм релокаций и PLT.
